Инструкция 1: Для разработчика интерфейса Студента (Ветка feat/student-ui)
Шаги для выполнения:

Откройте терминал в корневой папке проекта Parta.

Переключитесь на вашу рабочую ветку и обновите её:

bash
git checkout feat/student-ui
git pull origin feat/student-ui
Обновите зависимости (на случай, если они изменились):

bash
cd frontend
npm install
cd ..
Откройте вашего ИИ-агента (DeepSeek Harness).

Отправьте агенту следующий промт:

Промт для ИИ-агента:

text
Прочитай файл DESIGN_SPEC.md в корне проекта. Мы выполняем Спринт 2.
Твоя роль: Frontend-разработчик интерфейса Студента.
Твоя ветка: feat/student-ui.
Правило: Пиши код ТОЛЬКО в папке frontend/src/student/. Не трогай общие компоненты и папки других ролей.

Твои задачи:
1. Экран "Геймификация": Отобрази текущие показатели студента (XP, On-time streak, Streak Freezes). Добавь кнопку покупки "Заморозки стрика" (стоимость 200 XP), которая вызывает соответствующий API.
2. Экран "Пари (Wagers)": Создай форму, где студент может поставить часть своих XP на то, что сдаст задачу до дедлайна.
3. Командные задачи: В карточке задачи (если task_type = TEAM_PROJECT) добавь интерфейс отображения ролей (слотов) и кнопку "Занять слот".
4. Сделай git add, git commit -m "Student UI: gamification, wagers, team slots" и git push origin feat/student-ui.

# ПАРТА — Учебная платформа для мессенджера MAX

## Вход в приложение

### Через MAX

1. Откройте приложение по ссылке внутри MAX.
2. При первом входе появится экран выбора роли:
   - **Я студент** — подтверждение, затем аккаунт создаётся сразу;
   - **Я преподаватель** — нужен код `TEACHER2026`;
   - **Я администратор** — нужен код `ADMIN2026`.
3. После создания аккаунта роль сохраняется в БД, и при следующих запусках вход
   происходит автоматически по `external_id = max:<max_user_id>`.

Подпись запуска проверяется по `MAX_BOT_TOKEN`. Для локальной отладки допускается
`hash = "demohash"` или запуск backend с `PARTA_ENV=dev`.

### Демо-вход в браузере

Если приложение открыто в обычном браузере без параметров MAX, доступны ровно
три демо-аккаунта:

| Аккаунт | Роль | Код |
| --- | --- | --- |
| `max:000000001` | Студент | не требуется |
| `max:000000002` | Преподаватель | `TEACHER2026` |
| `max:000000003` | Администратор | `ADMIN2026` |

Другие аккаунты через браузерный демо-интерфейс выбрать нельзя. Коды можно
переопределить через `TEACHER_INVITE_CODE` и `ADMIN_INVITE_CODE`.

## Сборка и запуск в Docker

### 1. Подготовка демо-базы

Для браузерного демо-входа база должна содержать три демо-аккаунта. Команда
создаёт чистую SQLite-базу и наполняет её начальным сидом:

```bash
mkdir -p parta-data uploads
cd backend
go run ./cmd/seed-max -db ../parta-data/parta.db -file ./demo/max_seed.sql
cd ..
```

> Команда `seed-max` очищает пользовательские таблицы. Не запускайте её на базе
> с реальными пользователями.

### 2. Сборка образа

```bash
docker build -t parta .
```

Dockerfile собирает frontend через `npm run build`, компилирует Go-бинарник и
запускает единый сервер, который отдаёт и API, и статику frontend.

### 3. Запуск контейнера

```bash
docker run -d \
  --name parta \
  --restart unless-stopped \
  -p 8080:8080 \
  -e PARTA_ENV=production \
  -e MAX_BOT_TOKEN="your_bot_token_here" \
  -e TEACHER_INVITE_CODE="TEACHER2026" \
  -e ADMIN_INVITE_CODE="ADMIN2026" \
  -v "$(pwd)/parta-data:/app/data" \
  -v "$(pwd)/uploads:/app/uploads" \
  parta
```

После запуска сервис доступен по адресу: http://localhost:8080

`PORT` по умолчанию — `8080`. Чтобы использовать другой порт, задайте `PORT` и
пробросьте его в `-p`, например:

```bash
-e PORT=9000 -p 9000:9000
```

Для реального входа через MAX обязательно задайте `MAX_BOT_TOKEN`. Если он не
задан, браузерный демо-вход продолжит работать, а MAX-авторизация вернёт `401`.
